Démarrer

Trois étapes jusqu'à votre première déclaration

Vous pouvez développer toute l'intégration avant de recevoir votre clé : les formats, les statuts et les erreurs sont décrits intégralement ci-dessous.

Recevoir votre clé

Nous vous la transmettons en privé, personnellement. Elle commence par mtk_live_ et n'est communiquée qu'une seule fois : conservez-la dans un gestionnaire de secrets.

Vérifier le branchement

Appelez POST /api/v1/auth. Une réponse 200 confirme que la clé est valide et ouverte au suivi des livraisons. Cet appel ne modifie aucun colis.

Déclarer vos statuts

À chaque événement de tournée, ou en lot en fin de journée, envoyez le statut de chaque colis avec son code de suivi.

POST /api/v1/livraisons/statut à chaque événement de tournée

Corps

  • codeSuivirequisle code de suivi du colis, ex. PD-000123. La casse est indifférente. Vous pouvez déclarer tout colis dont la ville de destination fait partie de celles que vous desservez ; les autres répondent 404.
  • statutrequisl'une des 12 valeurs du catalogue.
  • dateISO 8601 — 2026-09-15 ou 2026-09-15T14:30:00Z. Obligatoire pour reporte et programme, ignorée pour les autres.
  • notefacultative, 150 caractères maximum.
{
  "codeSuivi": "PD-000123",
  "statut": "reporte",
  "date": "2026-09-15",
  "note": "Client absent, repasse mardi"
}

Réponse 200

{
  "issue": "applique",
  "codeSuivi": "PD-000123",
  "statut": "reporte"
}

issue vaut applique quand le statut a été enregistré, ou inchange quand le colis portait déjà ce statut. Renvoyer une déclaration déjà faite n'est jamais une erreur : vous pouvez rejouer sans risque après une coupure réseau.

POST /api/v1/livraisons/statut/lot en fin de tournée

Corps — 100 lignes maximum

{
  "livraisons": [
    { "codeSuivi": "PD-000123", "statut": "livre" },
    { "codeSuivi": "PD-000124", "statut": "reporte",
      "date": "2026-09-15" },
    { "codeSuivi": "PD-000125", "statut": "refuse",
      "note": "Refusé à la porte" }
  ]
}

Chaque ligne suit exactement les règles de l'endpoint unitaire.

Réponse 200

{
  "totalTraite": 2,
  "totalRefuse": 1,
  "resultats": [
    { "issue": "applique", "codeSuivi": "PD-000123", "statut": "livre" },
    { "issue": "applique", "codeSuivi": "PD-000124", "statut": "reporte" },
    { "issue": "refuse", "codeSuivi": "PD-000125",
      "code": "colis_introuvable",
      "message": "Aucun colis déclarable ne correspond à ce code de suivi" }
  ]
}

Une ligne en erreur n'empêche pas les autres d'être enregistrées. La réponse est 200 dès que le lot a pu être lu ; le détail ligne par ligne est dans resultats, dans l'ordre d'envoi.

Catalogue

Les 12 statuts que vous pouvez envoyer

Toute autre valeur est refusée. Envoyez la valeur exacte de la colonne de gauche.

Clôturent le colis définitif

Après ces statuts, plus aucun changement n'est accepté sur le colis.

  • livrecolis remis au destinataire
  • annulelivraison annulée à la demande du destinataire

Exigent une date champ date

Indiquez la date de la prochaine tentative, au format ISO 8601.

  • reportelivraison reportée à une date ultérieure
  • programmelivraison programmée à une date convenue

Échec de livraison

La livraison n'a pas pu se faire.

  • refusele destinataire a refusé le colis
  • hors_zonel'adresse est hors de la zone desservie
  • numero_erronele numéro de téléphone est erroné

Contact avec le destinataire

Suivi des tentatives d'appel avant livraison.

  • boite_vocaleappel tombé sur la boîte vocale

Bonnes pratiques

Ce qu'il faut savoir avant la mise en production

Quatre règles qui évitent l'essentiel des incidents d'intégration.

Rejouer est toujours sûr

Après un délai dépassé ou une coupure, renvoyez la même déclaration : si elle était déjà passée, vous recevez inchange, sans doublon de notre côté.

Préférez le lot

Trente colis rentrés de tournée tiennent en une requête sur /livraisons/statut/lot. Au-delà de 100, découpez en plusieurs lots.

Des dates au format ISO

2026-09-15, jamais 15/09/2026 : une date ambiguë est refusée plutôt que devinée, pour qu'un colis ne soit jamais relancé au mauvais jour.

Surveillez l'expiration de la clé

Quand une date d'expiration est programmée sur votre clé, les réponses réussies des sept derniers jours portent l'en-tête mathio-key-deprecation, avec cette date. Surveillez-le : une nouvelle clé vous est transmise avant l'échéance, sans interruption de service.

Premiers essais

Il n'y a pas d'environnement de test

Chaque statut envoyé s'applique à un colis réel. Pour vos premiers essais, nous vous confierons quelques colis de démonstration et vous communiquerons leurs codes de suivi.

D'ici là, vous pouvez tout développer : formats, correspondance des statuts, traitement des erreurs.

Votre clé

Elle est personnelle

Ne la placez jamais dans une URL, dans un dépôt de code, dans un journal ou dans une application exécutée chez vos livreurs : elle doit rester côté serveur.

En cas de doute sur une fuite, prévenez-nous : elle est révoquée immédiatement et une nouvelle vous est transmise.
